Fairseq's `transformer_sentence_encoder.py:243-276` initializes `inner_states` with the embedding representation and then appends each transformer layer output. For RoBERTa-large (24 layers), the list has embedding state 0 plus transformer layers 1-24. Therefore negative indices map as follows.

| Feature | Original creation | Fairseq state | Conventional RoBERTa layer | Pooling | Upstream normalization | Width |
|---|---|---:|---:|---|---|---:|
| T1 | IEMOCAP:24 / MELD:25 | `feat[-1] = state[24]` | 24 | BOS `[:,0,:]` | none shown | 1024 |
| T2 | IEMOCAP:25 / MELD:26 | `feat[-2] = state[23]` | 23 | BOS `[:,0,:]` | none shown | 1024 |
| T3 | IEMOCAP:26 / MELD:27 | `feat[-3] = state[22]` | 22 | BOS `[:,0,:]` | none shown | 1024 |
| T4 | IEMOCAP:27 / MELD:28 | `feat[-4] = state[21]` | 21 | BOS `[:,0,:]` | none shown | 1024 |

`hidden_states[0]` is the embedding output before transformer layer 1. It is not used here. There is no mean/max pooling, layer pooling, linear projection, or fusion during pickle creation. The only pooling is selecting the BOS token. XP04 later applies four independent BN modules, averages the four normalized tensors (`model_cm.py:751-772`), and sends that average into the text projection/GRU. Thus the intervention point can be before BN on T1-T4, but CMERC normally collapses them by equal averaging afterward.
