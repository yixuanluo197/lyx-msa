# 优先级与诊断统计：固定方案

本轮只用已有10次扰动的派生记录，不增加重复、不跑GPU、不拟合校准器。两个数据集完整Validation，五Seed分别计算；此前结果已被反复查看，本轮不是独立确认。

## 固定分析

1. 原μδ、翻转稀疏性、正确/错误组均值/中位数/样本标准差/分位数/零比例。原C固定区间[0,.4)、[.4,.6)、[.6,.8)、[.8,1]；每组同时报告原C均值，承认分箱内仍有C差异。正确或错误少于10条，或少于3个Dialogue，标记样本不足，不删除。
2. 在同一Dialogue内配对原C相近的正确和错误话语，不放回、caliper .02；最大化有效匹配数后最小化总C差。按utterance_index确定顺序，不使用行为量选配对。每原始话语在每Seed最多出现一次配对；这些是描述性配对，不是新的训练样本。
3. 对μ/δ报告配对差wrong−correct、正负及相等比例。区间按已冻结2000个Dialogue配对抽样，各Seed单独算均值后平均，不将五Seed当五份独立数据；缺少配对的抽样标无效，不静默减少Seed。预登记caliper只有一个，不据结果变动。
4. 原有三组5/5随机重复拆分重算μδ一致性；先汇总每Seed三拆分，再报告五Seed均值/样本标准差。大量零值可能造成秩相关误读，一并报告稀疏性。常量向量记NA。
5. 对扰动最大置信度的均值变化作Monte Carlo噪声描述。源std是ddof0，必须先换算：SE=std_pop/sqrt(10−1)，不能误用std_pop/sqrt(10)。delta/SE只作幅度与噪声比，不是delta显著性检验或其置信区间。没有改变CaliDist定义或新增评分输入。

## 文件责任与验证

主代理审计并复制8180行canonical特征、原三拆分结果、共享Dialogue抽样和已发布校准摘要，锁定来源hash；统计实现者独占scripts/diagnose.py、test_diagnostics.py与results统计产物；独立验证者独占scripts/verify_diagnostics.py和独立核验JSON。源码冻结后才正式计算。核对配对唯一性/阈值/最优匹配、常量NA、SE分母、区间共享抽样、原μδ与标签一致。

## 解释与停止

配对控制同一Dialogue和近似C，只减少部分混杂；不同语境等差异仍存在，不证明因果或严格条件独立。行为区分性与可重复性也不等于校准获益。置信区间是探索性、未做多重比较修正。所有分箱/腐蚀类型/指标均报告，不挑有利子群。

最终给出后续优先级报告，尤其评估是否值得固定评分结构检验10→30重复；GPU与原始数据任务均不在本轮执行范围。上传统计CSV、代码、审计与报告后停止。
