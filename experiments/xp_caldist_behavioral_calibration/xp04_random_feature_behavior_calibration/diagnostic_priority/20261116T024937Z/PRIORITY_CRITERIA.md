# 后续优先级的解释规则

本轮不根据统计结果挑选新的主校准器或最优扰动强度。排序依据是排除具体阻碍的价值与成本，不是为得到正结果扩大搜索。

1. 已完成的E1、μδ加性、冻结基线修正和C交互证据保留；没有稳定行为增量时，继续扩大评分模型的优先级低。
2. 稀疏μ及低拆分一致性提示测量可能受限；固定算法、仅增加重复的技术检验有明确动机，但不保证产生新的信息。对30重复的改善只能在未来实际测量，不能由本轮统计直接宣布。
3. 固定C分箱与同Dialogue近似C匹配用于检查组间方向、稀疏和支持量。均值差区间跨零不证明无效；反向差也不等于没有信息；任何非零差不证明可泛化或校准收益。
4. 统计结果如由稀少非零μ、少数Dialogue或有限overlap支持，必须降级解释。10条/3Dialogue标记仅为工程提醒，不代表达到统计功效要求。不同Seed结果共享话语、不是独立数据。
5. 单Seed视觉弱收益可登记为模态线索，不直接升级为已证实有效模态。原始数据机制Pilot和完整原始数据实验分别讨论；后者需要额外校准证据。本轮均不执行。

报告需要同时写明“先做什么”和“它能排除什么原因”，并保存全条件结果。重复Val上的诊断结论仍为探索性。
