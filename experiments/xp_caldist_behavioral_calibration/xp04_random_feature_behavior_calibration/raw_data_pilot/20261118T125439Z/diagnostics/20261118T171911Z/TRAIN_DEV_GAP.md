# Train Fit 与内部验证误差诊断

两套 Epoch 8 学生的 FP32/eval 误差均较公开初始化大幅下降，但 Fit 自身仍远离原兼容标准，同时出现约 1.5 倍的内部验证/Fit 误差比。因此存在泛化差距，但不能将失败完全归因于泛化；当前训练尚未达到兼容所需的拟合精度。

## 固定协议与数据边界

- 只读取原实验缓存 `local_only/{dataset}/train_prepared.pt`，沿用原始 `fit_indices`、`dev_indices` 和已经处理好的 Token ID。没有打开原始 pkl、官方 Validation 或 Test；不使用任何情绪标签。
- IEMOCAP：Fit 4747 条、97 个 Dialogue；内部验证 536 条、11 个 Dialogue。MELD：Fit 8989 条、934 个 Dialogue；内部验证 1000 条、104 个 Dialogue。分组互斥检查通过。
- 每个数据集依次加载公开 RoBERTa Large 初始化及原最佳 Epoch 8 学生，均为 FP32、`eval()`、禁用 TF32 和 autocast，batch size=4，右侧 padding。没有训练或调参。
- 直接复用原训练脚本的 `PreparedDataset`、`collate`、`student_features`、`evaluate`。取隐藏层 `[-1,-2,-3,-4]` 的 BOS，先在 FP32 计算平方差，再以 FP64 累加，按实际话语数和1024维平均，最后平均四层；末批按样本数加权。
- 启动前后均校验 Train 缓存、最佳学生权重/配置、原训练代码及配置 SHA-256。全部与原模型锁一致，原始资产保持不变。公开初始化权重 SHA-256 为 `047c85f0b96269cd62e6f732644f067004eebd95af5b5d35965ae2528f13bf38`。
- 单卡持续运行：IEMOCAP GPU 1、MELD GPU 3；设备 UUID、PID、完整命令和环境记于 `local_only/gap_launches.json`、`local_only/gap_{dataset}/launch.json`，日志在 `logs/train_dev_gap_{dataset}.log`。

## 分数据集判断

### IEMOCAP

- 公开初始化 → Epoch 8：Fit MSE 下降 96.334%，内部验证 MSE 下降 94.208%。说明蒸馏确实学习到了目标表示，并非完全没有有效训练。
- Epoch 8 Fit MSE=0.0282513673，对应总体 RMSE=0.168081；内部验证 MSE=0.0427955729。所有四层 Fit MSE 仍显著非零，连训练集都未达到旧协议逐层 RMSE≤1e-4 所要求的精度（对应逐层 MSE≤1e-8）。该比较仅解释失败，不开展或重跑官方 Validation 门。
- 当前重新计算的内部验证 MSE 与原 Epoch 8 选择记录差值仅 9.526e-11。两者均为 FP32/eval，微小差异来自分批和求和顺序；原模型选择记录可以复现。
- 内部验证比 Fit 更差，存在泛化差距；但 Fit 本身仍不够精确，因此“只要解决泛化就能兼容”不受本诊断支持。能否更充分记忆小样本以及是否存在框架差异，应结合另外两个诊断判断。

### MELD

- 公开初始化 → Epoch 8：Fit MSE 下降 97.789%，内部验证 MSE 下降 96.612%。说明蒸馏确实学习到了目标表示，并非完全没有有效训练。
- Epoch 8 Fit MSE=0.0229422063，对应总体 RMSE=0.151467；内部验证 MSE=0.0352255879。所有四层 Fit MSE 仍显著非零，连训练集都未达到旧协议逐层 RMSE≤1e-4 所要求的精度（对应逐层 MSE≤1e-8）。该比较仅解释失败，不开展或重跑官方 Validation 门。
- 当前重新计算的内部验证 MSE 与原 Epoch 8 选择记录差值仅 -2.572e-10。两者均为 FP32/eval，微小差异来自分批和求和顺序；原模型选择记录可以复现。
- 内部验证比 Fit 更差，存在泛化差距；但 Fit 本身仍不够精确，因此“只要解决泛化就能兼容”不受本诊断支持。能否更充分记忆小样本以及是否存在框架差异，应结合另外两个诊断判断。

## 解释限制与交付

- 此处 Fit 与内部验证都使用同一 FP32/eval 口径；不将训练日志中的 dropout 开启、FP16 autocast 训练损失与它们直接相减。
- 内部验证曾用于原训练的早停/最佳轮次选择，不能当作新的独立泛化集。这里是描述性误差对比，没有进一步选择超参数。
- 约1.5倍的差距不能单独证明特定因果原因，也不能排除教师目标的输入依赖问题；未据此修改目标、权重、Tokenizer或损失。
- 完整精度数字在 `results/train_dev_gap_{IEMOCAP,MELD}.json` 与 `.csv`；合并表 `results/train_dev_gap_all.csv`；差值/比值表 `results/train_dev_gap_comparison.csv`；可执行代码 `scripts/evaluate_train_dev_gap.py`。
- 本诊断没有新增模型、没有完整训练、没有官方 Validation/Test 推理、没有 XP04 概率验证，也没有原始文本干扰。
