# 小样本过拟合诊断

两套新初始化学生均完成预先固定的 500 次实际优化更新。IEMOCAP 总体 MSE 降低 99.8270%，MELD 降低 99.8982%，表明学生能够强烈拟合四层教师特征；但残差仍远高于旧兼容性标准要求，不能称为精确记忆或特征空间恢复。

## 设计与边界

- 每个数据集只从上次缓存的有效 Train Fit 选择 128 条话语；processed_text_sha256 与输入 Token ID 序列均互异，按对应 Seed 确定性打乱后选择，未按目标误差筛选。IEMOCAP 覆盖 71 个 Dialogue，MELD 覆盖 122 个 Dialogue。
- 初始化均为同一公开 RoBERTa Large（354,310,144 个 backbone 参数，不含 pooler/MLM 头），两个任务独立训练；没有读取上次学生权重、原始共享 pkl、官方 Validation 或 Test。
- 最后四层依次 [-1,-2,-3,-4]，均取 BOS 向量，每层 1024 维。损失为四层原始尺度逐元素 MSE 的平均，无标签、额外分类头、仿射映射或目标归一化。
- AdamW：lr=1e-5，betas=(0.9,0.999)，eps=1e-8，weight_decay=0；固定 500 步、microbatch=4、累积=4、有效 batch=16、梯度裁剪 1.0；每轮遍历重新打乱，累计 8000 次话语呈现，相当于 62.5 遍小样本集。
- 所有 encoder 参数参与训练；hidden/attention dropout 均在实例化前设为 0，并逐模块断言关闭。关闭 dropout 与权重衰减是拟合能力诊断的既定条件，与原正式蒸馏的正则化设置不同，不能据此单独归因于 dropout 或 weight decay。
- FP32 训练及 eval，不使用 AMP/TF32；nonreentrant gradient checkpointing。固定 step 0/25/50/100/200/300/400/500 对全部 128 条样本进行 FP32 eval，MSE 按 N×1024 逐层聚合，不是微批次均值的未加权平均。
- 使用原运行服务器 LOCAL_HOST，本地 GPU 0（IEMOCAP）和 GPU 2（MELD）。正式任务启动前分别进行了独立输出的 2 步工程 smoke；正式任务从公开权重重新初始化，smoke 不计为正式结果。

## 判断

1. **具有较强的近似拟合能力。** 两个数据集、四个层均大幅下降，排除了“学生前向完全不依赖训练参数”或“没有真实梯度更新”这一类简单故障。
2. **尚未证明能精确拟合。** 最终逐层 RMSE 为约 0.0221–0.0471，旧 RMSE 上限为 1e-4，对应必要 MSE 条件 1e-8；本诊断没有达到该量级。旧门槛还包含更严格的 MAE、allclose 与相关性要求，不能用损失降幅替代这些门槛。
3. **500 步后的非零残差不能证明架构不具备拟合能力。** 这里固定了学习率、优化步数和 batch，既未延长训练，也未进行超参数搜索；只能说明当前有界配置没有实现精确记忆。
4. **不能据小样本拟合推断独立泛化或 XP04 概率一致性。** 这些 128 条都参与本临时模型训练，只是容量诊断，不是独立性能验证。本轮未执行官方 Validation 或 XP04 概率检查。
5. 是否值得第二轮正式蒸馏，应同时结合本轮 Train/内部验证误差差距及同权重框架检查；本诊断单独不支持直接启动第二轮完整训练。
