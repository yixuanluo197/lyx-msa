# 发布与验证范围

本次公开上传由研究者在实验完成后明确授权“上传到lyx的github”。原始实验目录保持不变，公开副本新增于既有LYX仓库。

公开报告、配置、代码、全部10轮训练事件与统计CSV、损失曲线、冻结阈值、失败结果和核验记录。原始文本、逐话语清单、完整特征、学生/XP04权重、优化器断点、Tokenizer词表/BPE文件、原始媒体均留在本地。来源资产通过配置中的预训练ID、版本和SHA记录，不重新分发权重或授权数据。

脱敏只替换服务器路径、宿主机名及物理GPU UUID；Train准备记录中的逐行索引数组转为对应数量，不发布索引清单。训练目标、层序、损失、划分数量、epoch选择、数值门槛和实际指标均不改变。结构化训练事件完整保留，非JSON环境警告保留本地。

本地verification.json中verified=true指实验产物完整性、原输入未修改和执行边界核验通过；两数据集feature_gate_passed均为false。它不表示特征重建成功，也不表示概率已验证。概率状态必须保持NOT_RUN_FEATURE_GATE_FAILED、指标null。

本地原件SHA与脱敏公开字节SHA均在publication_manifest.json留档。历史模型锁及final_artifact_hashes.json记录本地原件，不能用公开占位符文件重算后冒充原运行字节。公开代码只做AST/格式/状态与记录一致性检查；本次发布不重新训练或重新访问Validation目标。

本轮训练进程未重启。交互监控中断后通过持久会话接管，无法由接管进程取得原子进程退出码；训练完成由完整epoch日志、摘要、模型锁、断点张量核验与最终特征验证共同确认。过程保留在results/execution_status.json。

公开CSV统一为LF换行，所有解析字段与行序保持不变；Python副本仅清理行尾空白，不改变语义。本地原件保持原样。
