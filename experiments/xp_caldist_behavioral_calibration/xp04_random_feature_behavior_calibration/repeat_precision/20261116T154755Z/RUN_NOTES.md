# 执行说明

## 历史协议与本轮授权

之前candidate_confirmation实验预登记三个独立10次块，不允许把30次事后替换为旧主设置。本轮用户明确批准独立开展10/30次精度对比，因此另建目录和预登记。旧报告、数据、模型及协议保持不变，三个10次结果全部保留；新增30次不按OOF结果择优。

## 资源与输入

仅local/user23 CPU统计和Logistic可靠性拟合；不加载Torch或CMERC，不执行GPU推理或生成随机噪声。模型Seed固定1475，已有Gaussian σ=0.05。源candidate交付清单329文件与相关历史输入共337个哈希已核验；最终再核对来源不变。

## 统计边界

30次包含原三个10次块，条件嵌套并非独立随机重复。Dialogue Bootstrap仅反映固定OOF输出下的话语组抽样变动，不含校准器重拟合、模型Seed或扰动重复不确定性。样本标准差/sqrt(K)仅称为逐次置信度均值的Monte Carlo标准误，不等同δ标准误。μ大量为零时高分半相关不代表广泛的可靠性信息。

## 停止边界

本轮完成、独立复核并交付GitHub后停止；不自动为其他Seed新增20次推理，不处理原始数据。

## 历史概率字段

Pilot的block0保存完整类别概率、预测及RNG，但未保存逐次log-probabilities；新增block1/2保存了log-probabilities。本轮保留可用字段，block0缺失原始log-probabilities明确标记，不从log(P)伪造模型原始输出。μ、δ、JS和校准均使用完整概率，不受该字段缺失影响。

## 预检后的报告修正

历史K10预检完成后，仅将报告主模型的CI判断限定为candidate=M_gaussian，避免把μ-only/δ-only消融区间归给主模型。分析、拟合和协议未改；正式分析哈希记录修正后的报告脚本。
