# 实验一　MELD 语义改写与行为指标诊断

**状态：计算诊断完成，双人盲审待回收。** 主候选仍是原预测类别支持度下降 D_pred。它补充了 μ 无法记录的未翻转变化，但目前无法确认它比原始置信度提供稳定增量。D_margin 与 D_pred 高度重叠，适合作为替代定义或单独消融。全分析基于已探索过的 Validation。

## 输入与分析口径

使用既有 MELD Seed 67137、203 对匹配话语（406 条、80 个 Dialogue）及 1,624 条存档干扰条件。1,544 条成功和 80 条失败均保留。语义改写是主范围，中性追加是 AI 审核对照。每个家庭保留两个固定版本，两边都满足完整 K=2 及相应审核条件才形成可分析配对。复用 2,000 次 Dialogue Bootstrap 的原始抽样。分析先在 Dialogue 内对有效配对平均，随后对 Dialogue 等权。正负方向如下。输入与配对来自[上一轮冻结协议](../../20261120T170835Z/configs/EXPLORATORY_PROTOCOL.json)。

定义：

- μ 为干扰版本的「翻转 × 干扰后最大概率」均值，Flip Rate 为纯翻转比例。
- δ 为平均最大置信度变化取绝对值，JS 为两个版本与干净概率分布的自然对数 JS 均值。
- D_pred 固定追踪干净输入的预测类别，计算该类干预前概率减干预后平均概率。
- D_margin 固定追踪原预测类别对最强非原类竞争者的概率差，再计算干预前的间隔减干预后的平均间隔。翻转时该版本间隔为负。
- D_C 为干扰后最大置信度均值减干净最大置信度。排序预先采用 −D_C（置信度下降较大一方为风险较高）。
- V_C 为两个干扰版本最大概率的样本标准差（ddof=1）。K=2 时只由两次置信度的绝对差决定。

## 语义改写的 AI 审核配对

主范围 86 对、57 个 Dialogue，支持率 86/203=42.4%。下表的差值为错误减正确，CI 为 95% Dialogue Bootstrap。配对排序以平局计半分，原始置信度参照为 53.51%，干净 Top-1/Top-2 间隔参照为 52.05%。这些排序属于覆盖样本内的条件诊断。

| 指标 | 差值 [95% CI] | 配对排序 |
|---|---:|---:|
| μ | 0.04982 [0.01407, 0.09067] | 56.58% |
| δ | 0.00697 [−0.01516, 0.02880] | 50.29% |
| JS | 0.00515 [−0.00081, 0.01142] | 51.46% |
| Flip Rate | 0.13012 [0.04402, 0.22341] | 58.33% |
| D_pred | 0.05488 [0.01987, 0.08986] | **62.57%** |
| D_margin | 0.08950 [0.02879, 0.15284] | 60.82% |
| D_C（按 −D_C 排序） | −0.03562 [−0.06295, −0.00769] | 62.28% |
| V_C | 0.00604 [−0.01180, 0.02452] | 54.68% |

D_pred 减原始置信度的配对排序差为 **+9.06 个百分点 [−7.35, +25.15]**，减干净类别间隔为 **+10.53 个百分点 [−6.36, +28.37]**，减 μ、δ、JS、Flip Rate 的四项排序差区间也均包含 0。D_C 保留方向后比无方向 δ 的点估计高，在这一批语义改写上与 D_pred 的整体排序接近。这些量的条件差异可以存在，同时单指标相对置信度的排序优势仍未确定。

收紧置信度差后，≤0.02 的 45 对／35 个 Dialogue 中，D_pred 差值为 0.05913 [0.00952, 0.11457]，相对置信度排序差为 +12.86 个百分点 [−8.33, +33.33]。≤0.01 的 29 对／23 个 Dialogue 中，D_pred 差值为 0.03406 [−0.03165, 0.09524]，排序差 +6.52 个百分点 [−21.57, +34.67]。严格范围的信息量较小，当前不能把区间变化归因于唯一原因。中性追加对照的 AI 审核范围为 68 对／48 个 Dialogue，四个新指标的错误减正确区间均含 0。

## 稳定错误与指标重叠

- 改写主范围的 86 个错误样本中，60 个两个版本都不翻转（69.8%）。其中 33 个 D_pred 为正、27 个为负，中位数下降 0.00522，四分位数 [−0.03523, 0.04015]。模型有时在保持错误类的同时减少支持，也有时增加支持。这些结果无法定位错误本身的来源。
- 53 对／39 个 Dialogue 的两边 μ 都为 0。D_pred 在 31 对错误方较高、22 对正确方较高，等 Dialogue 排序 59.83%。其差值 CI 为 [−0.01262, 0.05895]，相对置信度的配对排序只高 1.71 个百分点 [−21.32, +25.00]。在这批没有翻转的样本上，严格有 D_pred = −D_C；这两项观测的是同一个量。
- 整体语义改写审核范围中，D_pred 与 D_margin 的 Pearson / Spearman 为 0.982 / 0.985，D_pred 与 D_C 为 −0.643 / −0.665，D_pred 与干净置信度为 0.132 / 0.077。后二者相关较小仅描述匹配队列中的边际关系，不能推出条件独立或正确性评分增量。配对内对控制变量作的诊断和这些描述性相关应分开理解。
- δ 恒等于 |D_C|。JS 记录变化幅度，本轮语义改写中正确方或错误方 JS 较大的配对各 43 个。V_C 的方向不直接对应置信度增或减，在完整审核样本上的区分弱。

## 当前决策

保留 D_pred 为主候选、D_margin 为次候选，D_C 作为方向对照。K=2 的 V_C 保留描述用。所有原指标照常保留。这里尚未评估「强干净基线＋行为」的独立预测表现，没有拟合评分器。86 对属于已有 AI 审核的重复分析，不能替代两名独立人审。当前人工一致通过配对为 NA，未收到真实人工审核结果，不能把 AI 通过换算成人工通过。

人工完成后，在新的输出目录用两份真实审核表的共识重复相同统计，先报告有效配对／Dialogue 和排除理由，再解释主候选。K=5 按原方案依赖人工有效范围，本轮未启动。

计算核对通过 11 项冻结输入 SHA，以及原四指标跨两家庭、三配对范围的 24 项旧排序区间复算。仅使用保存概率，无新推理或训练。

独立复算 3,501 个目标指标及 384 个聚合与区间数值，聚合最大绝对误差为 `3.33e-16`。本页公开汇总诊断，完整文本盲审材料和逐话语诊断留在本地。
