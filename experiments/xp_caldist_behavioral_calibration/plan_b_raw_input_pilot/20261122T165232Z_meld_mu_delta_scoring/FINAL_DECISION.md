# MELD K=2 的 μ、δ 可靠性评分

**δ 的点估计优于 μ，但没有稳定超越干净置信度。** 两者合用没有提高单独 δ 的表现，加入强干净基线后五项指标的点估计均变差。本轮证据不足以进入五折、五 Seed 正式验证。

## 数据与公式核验

本轮只使用 MELD Seed 67137 的历史语义改写概率。核查全部 2,976 条干净预测和 5,952 个计划版本的对应关系，沿用原先两版均通过的 141 条话语。拟合组 72 条来自 72 个 Dialogue，其中 21 条原预测错误。评估组 69 条来自 69 个互斥 Dialogue，其中 25 条错误。两个角色均来自历史 Train 数据，评估组此前已经查看。

- μ 是两版的翻转指示乘以干扰后最大概率，再取平均。
- δ 是干净最大概率与两版干扰后最大概率的均值之差的绝对值。

从 282 条完整概率重新计算，两个指标和历史正式实现逐话语一致，最大绝对差均为 0。完整 K=2 资格由历史两次 AI 审核和编码推理记录确定，单版成功与零版成功均保留在核验计数。六组使用相同的 72 条话语计算拟合组标准化，使用相同的 69 条话语评价。E0 和 E1 的参数逐项复现历史共同样本基线，最大绝对差为 0。[公式核验](results/formula_verification.json)，逐版本复算保存在实验机。

## 预测正确概率

逻辑回归固定使用 L2、C=1。C 先按历史协议转换成 logit。输出 R 是原预测类别正确的概率。ECE15 按 R 的等宽分箱衡量二分类正确性校准。AUROC 和 AUPRC 以错误为正类。

| 输入 | Binary NLL ↓ | Brier ↓ | AUROC ↑ | AUPRC ↑ | ECE15 ↓ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始 C 直接作为正确概率 | 0.60597 | 0.20878 | 0.71818 | 0.58905 | 0.13136 |
| E0 C | 0.59051 | 0.20244 | 0.71818 | 0.58905 | 0.12011 |
| E1 C + Margin + Entropy | **0.58346** | **0.19789** | **0.73727** | **0.63311** | **0.11947** |
| E2 C + μ | 0.60177 | 0.20781 | 0.71364 | 0.57953 | 0.13923 |
| E3 C + δ | 0.58724 | 0.20082 | 0.72182 | 0.59848 | 0.12540 |
| E4 C + μ + δ | 0.59718 | 0.20543 | 0.71182 | 0.58917 | 0.12789 |
| E5 C + Margin + Entropy + μ + δ | 0.58951 | 0.20052 | 0.72727 | 0.61371 | 0.16607 |

下表以 NLL 降低为正改善，区间采用 2,000 次评估组 Dialogue 配对 Bootstrap。所有评分器共享抽样，参数保持固定。区间描述当前固定评分器的评估波动，未校正多重比较。

| 比较 | Binary NLL 改善 | 95% CI |
| --- | ---: | --- |
| E2 相对 E0 | −0.01126 | [−0.02839, 0.00222] |
| E3 相对 E0 | +0.00327 | [−0.00151, 0.00835] |
| E3 相对 E2 | +0.01453 | [−0.00089, 0.03401] |
| E4 相对 E2 | +0.00459 | [−0.00361, 0.01314] |
| E4 相对 E3 | −0.00994 | [−0.02796, 0.00464] |
| E5 相对 E1 | −0.00605 | [−0.02594, 0.01068] |

E3 的 Brier、AUROC 和 AUPRC 点估计优于 E0，三个改善区间均跨零，ECE15 点估计反而略高。E4 的 NLL 比 E2 低，但高于表现更好的单指标 E3，缺乏互补证据。E5 的 NLL 和 ECE15 均高于 E1，未见超越强干净基线的信号。E0 的 NLL 比原始 C 低 0.01546，区间为 [−0.08869, 0.10473]。[全部指标及区间](results/scorer_metrics.csv) · [配对对照](results/paired_contrasts.csv)

## 正误分布与系数

μ 在拟合组有 64/72 条为零，在评估组有 61/69 条为零。评估组只有 8 条非零，其中 2 条原预测正确、6 条错误。评估组 δ 均值在正确和错误话语中分别为 0.03767 和 0.06139。E2 的 μ 标准化系数为 +0.08948，E3 的 δ 标准化系数为 −0.03676。评分器以正确为正类。系数描述在本拟合数据和给定协变量下的关联，不能用来归因干扰响应或保证新组方向。样本数、非零 μ 和错误支持有限。[正误分布](results/correct_wrong_distributions.csv) · [全部模型系数](results/coefficients.csv)

## 后续决策

δ 可以保留为后续预设候选，μ 保留为置信度加权翻转的诊断量。继续验证优先用固定方案和新独立 Dialogue 检验 δ 相对 E1 的增量，样本设计需覆盖更多错误话语。本轮仍处于二分类正确性评分，结论不外推到完整七类校准。全程没有重新生成干扰、推理或训练 CMERC，也没有访问 Test 或官方 Validation。
