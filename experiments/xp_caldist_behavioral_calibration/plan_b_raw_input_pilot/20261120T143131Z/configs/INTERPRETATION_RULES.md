# Pilot 解释边界（官方 Validation 推理前记录）

- 先完成两个新 Baseline，再执行两数据集各120条原始干扰 Pilot。任何单次内部验证改善都不作为正式性能结论。
- Baseline 用固定 Train 内部 Dialogue dev 选轮次；官方 Validation 只在模型冻结后评估。所有预定干扰条件均保留，效果差不是删除条件的理由。
- 120条为预声明分层样本，覆盖类别、Dialogue、原正确性及置信度；其整体准确率、翻转率等不是总体无偏估计。MELD仅缺失音频的目标行不进入共同音频/文本目标池，原Dialogue上下文仍保留该行。
- 不稳定性与预测错误不是同一概念。μ是置信度加权翻转均值，δ是原最大置信度与干扰平均最大置信度之差的绝对值；分别报告未加权翻转和平均绝对置信度变化，避免混淆。JS使用自然对数。
- Dialogue配对bootstrap控制组内相关性，不自动消除Dialogue间混杂。固定0.1置信区间比较只是粗分层控制；额外提供同Dialogue×置信区间内正确/错误均有支持的匹配分析。支持不足时报告NA和支持率，不声称已证明控制Dialogue后具有增量价值。
- MELD抽样优先覆盖不同Dialogue，120目标可能多数每Dialogue仅一条，因此同Dialogue匹配支持可能很低；这是预先已知的设计局限，不在看到干扰结果后更换样本。
- 全部区间与多个条件比较均为单Seed探索性诊断，没有经预定独立验证的正式改进声明；不能据此宣称跨Seed稳定。
- 文本审核明确记录AI或人工方法。无实际听审时，音频客观信号QC不能证明原情绪标签保持。仅通过信号QC的音频行为单列探索分析，可按干净输入原正确性分组，不用原标签计算其扰动后准确率/校准或Correct-to-Wrong结论。
- 真实干扰与历史随机特征干扰使用不同特征和新训练Baseline，历史对比只能描述观察差异，不能隔离证明原始干扰更优。
- 本轮不拟合可靠性评分、不训练CaliDist模块、不增加Seed、不用Test，不根据官方Validation结果更改提取器、训练协议或采样。
