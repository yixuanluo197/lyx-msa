# MELD 行为指标筛选建议

**保留分解后的逐次响应，评分候选保持简洁。** 现有数据足以区分「换了类别」「更有信心」「原类失去支持」和「分布重排」。目前无需为这些现象再造一个合成分数。[响应分解报告](PREDICTION_RESPONSE_DECOMPOSITION.md)

| 取舍 | 指标与理由 |
|---|---|
| 必须保留 | 逐次的 flip、ΔC、ΔP 与完整七类概率。Flip Rate 表示类别稳定性，D_pred 表示原类有符号支持变化，JS 表示整体分布重排。三者测量的对象不同。原 μ 保留作历史可比指标。 |
| 可以合并 | δ 和 D_C 共用一个有符号来源，δ 可从 D_C 取绝对值。K=2 下平均及最大绝对 ΔC 可由 δ 和 V_C 精确导出。两版均未翻转时 D_pred 与 −D_C 相同，整体仍保留两者用于分解翻转后的差异。 |
| 条件诊断 | D_margin 的竞争类信息确实存在，但与 D_pred 的完整 AI 语义改写 Spearman 为 0.976。保留逐次竞争差和汇总，作为 D_pred 的替代或单独消融。平均／最大绝对变化、原概率标准差、置信度上升／下降次数和响应模式用于解释。V_C 在 K=2 仅由两次最大概率的差决定，当前适合描述。 |
| K=5 优先保留 | **D_pred、Flip Rate、JS、D_C**。并行复算老 μ、δ 以连接历史。把 V_C 作为重复性检查，用不重叠的版本组合检验离散估计是否稳定。报告分母和通过率，增加版本不增加独立 Dialogue 数。D_margin 作为次要对照。 |
| 需要后续评分验证 | 首先验证「干净置信度／强干净基线 + D_pred」的留出预测表现。若要验证间隔信息的独立性，再比较单用 D_pred 与加上 D_margin 或其竞争类分量。−D_C 作为低复杂度方向对照，特别检查发生翻转时它是否仍能替代 D_pred。需要按 Dialogue 留出并作配对评价。 |

## 对七个问题的回答

1. **μ 的主要作用是描述类别翻转。** 未翻转时为零，翻转时附带对新预测类别的最大置信度权重。应同时保留纯 Flip Rate，以免把翻转次数和翻转后的置信度混读。
2. **δ 确实丢失方向。** 语义改写的 AI 配对中，有符号 D_C 的错误减正确为 −0.03562，95% 区间 [−0.06295, −0.00769]；δ 的区间跨零。方向值得记录，是否提升留出预测仍需验证。
3. **D_pred 补足未翻转时的支持度变化。** 两边 μ 均为零的 53 对仍能得到连续响应，D_pred 排序为 59.83%。相对原始置信度的差为 +1.71 个百分点，其区间跨零。能量化新响应不等同于能可靠识别错误。
4. **D_margin 在定义上增加了竞争类别变化。** 它与 D_pred 高度重叠，特别是在无翻转范围。当前保留其竞争类诊断价值，暂无理由默认双入模。
5. **JS 能反映概率重新分配。** 分布的其他类别有变化时，即使 argmax 不变且最大概率接近，JS 仍能响应。需要由完整类别概率判断哪个类别获益或失去支持。
6. **V_C 在 K=2 值得保存用于诊断。** 它提供两版之间离散程度，样本量只有两个版本，不能据此确定稳定的波动特征。语义改写 AI 范围的 V_C 正误差和相对置信度排序差区间均含零。
7. **优先使用现成的响应分量。** 按是否翻转分别看 ΔC 和 ΔP，翻转时再记录「新赢家在同一类别上的概率增量」及「赢家对原类的优势」。这两项可用于解释 C 上升而 P 下降，暂不把它们变成新评分特征。

D_pred 的主要排序对照来自反复探索的 MELD Validation。自动 QC 和 AI 审核均为探索性，双人确认范围目前为 NA。本轮止于离线结果，等待审核。
