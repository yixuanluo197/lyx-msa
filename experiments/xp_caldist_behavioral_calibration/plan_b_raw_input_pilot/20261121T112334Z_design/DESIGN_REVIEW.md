# Plan B 六阶段方案科研与工程审阅

**审阅结论**　方案可以继续，先在 MELD 验证语义保持改写能否补充干净输入的置信度。Sample Corruption 作为第二种干扰验证。Assertion 和 Probe 合并为可选的合成元文本压力测试。

同一批 86 对 AI 审核通过的 MELD 语义改写样本中，事后复算的 D_pred 配对排序一致率为 62.6%，原始置信度为 53.5%，差值的 95% Dialogue Bootstrap 区间约为 −7.3 至 +25.1 个百分点。置信度差收紧至 0.01 后，仅余 29 对、23 个 Dialogue。该信号用于确定候选优先级，增量仍需留出数据检验。人工盲审尚未完成。[既有匹配范围与指标](../20261120T170835Z/MELD_TEXT_RELIABILITY_REPORT.md)

## 必须修改

### 固定哪些行为指标提供不同信息

设 c 是干净输入预测类别，p 是干净概率，q_i 是第 i 个干扰版本的概率，C_clean 和 C_i 分别是两次预测的最大概率。

| 指标 | 建议定义与角色 |
|---|---|
| D_pred | p(c) 减去各版本 q_i(c) 的均值。作为主候选，保留符号。未翻转时仍可能记录原预测支持下降。 |
| D_margin | 干净的原类领先间隔减去干扰版本间隔的均值。固定原预测类别 c，每个版本的间隔为 q_i(c) − max_{j≠c} q_i(j)，翻转后允许为负。用作次候选。 |
| D_C | mean(C_i) − C_clean。保留方向，用于诊断。 |
| V_C | Std(C_1, …, C_K)。固定样本标准差口径，用于重复性诊断，待 K=5 结果再考虑入模。 |

- 按目前实现，δ = |D_C| 恒成立。δ 是先平均再取绝对值，不同于平均绝对变化。若所有版本均未翻转，则 D_pred = −D_C。因此 D_pred 能补上 μ 的零值盲区，与置信度变化的独立性仍需检验。
- D_margin 等于 D_pred 加上最强竞争类别的平均概率变化。量化竞争类增量后，再判断两者是互补还是只需保留一个。若逐版本重新计算当次 Top-1 减 Top-2，得到的是当次冠军对亚军的优势，翻转后无法描述原类别失去领先的程度。
- K=2 时 V_C 的样本标准差等于 |C_1 − C_2| / √2，易被单个版本主导。各版本仍坚定支持原错误类别时，D_pred 也可能很小。仅凭行为指标无法定位错误究竟来自文本、上下文还是其他模态。[原指标计算口径](../20261120T170835Z/MELD_TEXT_RELIABILITY_REPORT.md)

### 分开匹配机制分析、评分拟合和独立评价

正确／错误 1:1 配对用于回答同一 Dialogue、置信度相近时的条件差异。正式评分评价应使用保留自然错误率的完整留出队列。预先固定质量门、生成失败回退到仅干净置信度的规则，以及覆盖率、有效覆盖子集和完整队列结果的报告方式。人工通过的复用 Validation 仍是探索数据。错误原因只做有证据的案例解释。

### 做严格折外训练并明确 Test 的历史边界

整段 Dialogue 应从对应折的监督训练、早停、checkpoint 选择和数据驱动统计量估计中排除。当前方案需逐折完成 RoBERTa 监督微调、M³Net 训练、仅训练侧 Dialogue 难度计算和 CMERC 训练。冻结公开 Wav2Vec2 和固定 Tokenizer 可共享，视觉特征需确认其生产没有使用目标折本地监督。现有难度用到训练话语的真实类别概率，因此要按折重建。[Plan B 训练协议](../20261120T143131Z/configs/PLAN_B_PROTOCOL.json) · [折外预测组合参考](https://pubmed.ncbi.nlm.nih.gov/17910531/)

OOF 行可训练评分器。若在 Train 内估计整条链的泛化表现，要额外划出共同隔离的组作为最终评价，或做真正的嵌套分组验证。直接对已汇总 OOF 表做第二层随机切分，无法保证产生评分训练特征的基础模型都未见过评分评估 Dialogue。官方 Test 此前已有旧 XP04 结果。Plan B 锁定后只进行一次预定评估，明确写「Test 未参与本方案选型」，并核查历史结果是否影响选型。[模型选择偏差研究](https://www.jmlr.org/beta/papers/v11/cawley10a.html) · [旧 XP04 执行记录](../../posthoc_calibration_baselines/20261109T013029Z/TEST_EVALUATION_COMPLETE.json)

### 分别验收正确性评分和多分类校准

先用 L2 Logistic Regression 估计 R = P(原预测正确)，以 Binary NLL 为主指标，Binary Brier、AUROC、AUPRC 为辅。错误识别统一以错误为正类，使用 1 − R 排序。比较同一自然分布队列上的配对 Dialogue 区间。除 E0 最大置信度外，增加只使用干净输入的强基线 C＋Top-1/Top-2 间隔＋熵。首轮只给强基线加 D_pred，再单独考察 D_margin，E1 保留历史指标对照。

评分有增量后，单独验证概率映射。可以预先设计保留预测类别的正温度映射方案，明确可达到的置信度范围、并列与数值处理。L 类概率向量的最大值至少为 1/L，因此更小的 R 无法直接作为保留原类后的最大概率。与标准 Temperature Scaling 及采用同样映射的只用置信度方案比较。以 Multiclass NLL 为主，Brier、ECE15 为辅。若每条 argmax 保持，Accuracy、Macro-F1 和 Weighted-F1 都应完全一致。[Temperature Scaling 原始论文](https://proceedings.mlr.press/v70/guo17a.html)

## 建议优化

- **小规模比较 K=2 和 K=5。** 在同一批目标和同一审核门下比较，额外用互不重叠的版本组合检查重复性。直接比较 K=2 与包含这两版的 K=5 会因共享版本抬高表面一致性。同一话语的多个组合不得按独立样本计。记录覆盖率、推理和人工审查成本。若 K=2 已足够稳定，把增量资源投向更多不同 Dialogue。
- **Sample Corruption 先做一种轻度字符修改。** 每句 1 处适合做候选起点，2 处只给可编辑文本足够的句子。以长度分布、可编辑字符比例和实际 Token 变化确定档位。短句和无法安全编辑的话语单独标记。词删除与字符修改分开，明显改动情绪的版本归压力测试。
- **Assertion 和 Probe 共用候选情绪，保留各自对照。** 候选由固定随机规则产生，与真实标签和原预测独立。恰好一致的样本保留。Assertion 的 A2−A1 在同一候选情绪下对照来源描述。Probe 的 P2−P1 同时改了显式情绪词和询问具体程度，宜加同候选的陈述式对照。优先看候选情绪概率变化并检查长度、位置和截断。当前 ERC 对追加的元文本做分类，反应可以来自情绪词或文本和音频的不一致。单版本条件的 V_C 缺乏重复性含义。
- **预先冻结投入门槛。** 指定一个主对比，例如强干净基线加 D_pred 相对强干净基线的 Binary NLL 改善，写明最小有用效应、Dialogue 区间和最低可用覆盖。其余指标、类别与子集作次分析。若区间过宽，优先扩大有效 Dialogue。五 Seed 衡量训练随机性，不增加同一 Test 的独立 Dialogue 数。

## 可以保留

- 复用冻结的 MELD Seed 67137，单次仅修改一个目标话语，完整 Dialogue 推理。保留双人独立盲审、分歧和失败记录。
- 保留 μ、δ、JS、Flip Rate 及 Pearson、Spearman、分组 Bootstrap。相关性用于诊断重叠，增量靠相同留出队列上的对照判断。
- 先 MELD、后 IEMOCAP，达到推进条件后再扩展五 Seed。若最终验证只用文本操作，结论限定为多模态 ERC 模型上的文本扰动校准。音频行为的结论需要单独的听审和留出验证。

## 暂不建议开展

- 将 Assertion、Probe 作为可靠性主线的前置条件，或第一轮就把它们与标签保持干扰混合。两者合并为可选压力实验。
- 同时投入高强度损坏、多删除比例、E3 和 MLP。优先确定一个连续指标相对强干净基线是否有独立收益。
- 直接启动两个数据集的五 Seed、五折全链训练。若每个 Seed 都独立训练五折和一个最终模型，约为 60 条监督训练链，未计额外调参。可以先用 MELD 单 Seed 的严格分组留出验证。评分拟合与评价用的 Dialogue 都需要在基础模型训练和早停前预留。

|---|---|---|
| 1 | MELD 现有改写双人盲审与指标诊断 | 核对覆盖、有效 Dialogue 和未翻转样本中的 D_pred 信号，保留 D_margin 为次候选 |
| 2 | 小规模 K=2／5 重复性验证 | 综合稳定性、覆盖率及成本定 K |
| 3 | 提前做实验六的第一段，MELD 单 Seed 严格分组留出 | 验证加入 D_pred 能否超越强干净基线，再决定是否投五折全链训练 |

| 5 | 全链 OOF、置信度映射、IEMOCAP、多 Seed 及锁定后的 Test | 独立验收正确性评分和多分类校准，固定全部规则后评价 Test |
