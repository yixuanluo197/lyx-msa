# Causal IEMOCAP single-seed figures

One paired training seed (1937), split seed 1475; no error bars, significance tests, smoothing, or test-derived figure selection.

Convergence shows all 80 observed epochs. Validation dots identify each earliest maximal W-F1 epoch. Loss panels show recorded epoch means and actual coefficient-weighted CC/MSCL/CSCL; their scales differ and their magnitudes do not quantify gradient contributions. Position panels show all three preregistered validation thirds with fixed symmetric axes around zero. Classification improvement is positive; calibration improvement is negative.

SVG text is editable; PDF uses embedded TrueType fonts. Each figure is 7.2 inches wide. PNG files are Matplotlib previews. Companion CSV files contain all plotted values without dialogue IDs.
